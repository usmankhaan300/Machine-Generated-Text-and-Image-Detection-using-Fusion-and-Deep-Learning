# Machine-Generated Text and Image Detection using Fusion and Deep Learning

This repository contains the official PyTorch implementation and research code for the MSCS thesis: **Machine Generated Text and Image Detection using Fusion and Deep Learning**. The project introduces a robust multimodal deep learning framework specifically designed to detect AI-generated health misinformation across textual and spatial (image) modalities.

**Note on Dataset:** The dataset used for this project (LLaMA text and WGAN-GP images) is currently stored on a secure drive due to size limitations. The data loading scripts in the Colab notebooks are configured to fetch data from Google Drive.

## 🚀 Key Features and Methodological Innovations

* **Multimodal Architecture:** Combines mathematically disciplined spatial networks (EfficientNet-B7) for images and extensively contextualized bidirectional transformers (BERT) for text.


* **Unified Zero-Padded Fusion (UZPF):** A novel mechanism that dynamically handles missing modalities (single-modality inputs) by zero-padding the missing dimension, preventing architectural bottlenecks without requiring strictly paired data.


* **Generative AI Detection:** Capable of detecting highly convincing synthetic health narratives generated by the LLaMA-3.1-8b-instant Large Language Model.


* **Medical Deepfake Detection:** Identifies microscopic, high-frequency generative artifacts in synthetic MRI and CT scans generated by a Wasserstein Generative Adversarial Network with Gradient Penalty (WGAN-GP).


* **State-of-the-Art Regularization:** Implements Label Smoothing (0.1) to counteract model overconfidence, Cosine Annealing Learning Rate scheduling for stable convergence, and Gradient Clipping (1.0) to maintain mathematical stability.



## 📊 Dataset Overview

The experiments utilize a meticulously balanced multimodal dataset containing 6,064 instances for training, validation, and blind testing:

* **Text Modality (3,032 instances):** Real human-authored medical news scraped from reliable sources vs. synthetic medical texts generated via LLaMA-3.1-8b-instant.


* **Image Modality (3,032 instances):** Authentic MRI and CT scans from the Kaggle BTD dataset vs. highly realistic synthetic scans synthesized using WGAN-GP.

## 💻 Code Structure & Usage

The repository contains scripts for both training (`SOTA BENCHMARK LOOP`) and inference (`EVALUATION LOOP`).

### 1. Data Preprocessing

* **Images:** Min-Max scaled to [0, 255], channel-stacked to 3-channel RGB, and resized to $224 \times 224$ pixels. Data augmentation includes random rotation (15 degrees) and horizontal flipping (p=0.5).


* **Text:** Processed using the WordPiece tokenizer (`bert-base-uncased`), padded/truncated to a maximum length of 128 tokens.



### 2. Model Initialization (`DynamicFusionNetwork`)

The `DynamicFusionNetwork` class allows you to dynamically pair different spatial and textual backbones.

```python
# Initialize the SOTA model
model = DynamicFusionNetwork(img_model_name='EfficientNet_B7', txt_model_name='BERT')

```

### 3. Training

The training loop utilizes Automatic Mixed Precision (AMP) with a `GradScaler` to prevent out-of-memory errors during heavy gradient backpropagation on GPUs. It runs for 15 epochs using the AdamW optimizer with a micro-learning rate of 1e-5 and weight decay of 1e-3.

### 4. Evaluation

The evaluation script loads the saved weights (`.pth`) and outputs the Accuracy, Precision, Recall, and F1-Score. It also utilizes `seaborn` and `matplotlib` to automatically generate and save the Confusion Matrix and ROC-AUC curves.
